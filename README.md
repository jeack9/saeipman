# saeipman

### :clipboard: 프로젝트 소개
SAIEPMAN은 소규모 건물 소유주들이 임대 관리를 보다 효율적으로 수행할 수 있도록 지원하는 플랫폼입니다. 복잡한 기존의 임대 관리 시스템을 간소화하고, 직관적인 사용자 인터페이스를 제공하여 모든 사용자가 쉽게 접근하고 활용할 수 있도록 설계되었습니다.

### 🗒 주요기능
- 직관적인 UI : 사용자가 쉽게 이해하고 사용할 수 있는 인터페이스.
- 월세/관리비 관리 : 월세와 관리비를 간편하게 관리할 수 있으며 결제 기능을 지원.
- OCR 기능 : 소유 건물 등록 시 OCR 기능을 통해 효율적인 데이터 입력 지원.
- 임대관리 : 임대 계약 및 관련 사항을 체계적으로 관리.
- 민원 서비스 :  임대인과 임차인 간의 원활한 소통을 위한 서비스.
